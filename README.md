# アルティメットカードプラグイン
カードを使用することでアルティメットアビリティの発動を可能にするプラグイン。

# アルティメットアビリティ
## テイクオフ
**チームメイトと共に上空に飛び出し、滑空する。**

### アイテムを使用すると離陸準備体制になる。
プレイヤーは使用場所から1m上空の位置に固定される。
チームメンバーはスキル展開中の半径4m以内にいる状態でチャットに来る通知をクリックすると離陸に同行できる

### アイテムを再度利用すると離陸を開始する
1秒間エンジンスピンアップの時間がかかりスピンアップ後に高速で離陸する。離陸完了後、各プレイヤーは自力で航行を開始(エリトラを手動で展開)する必要がある。

_エリトラの展開を忘れるとそのまま落下死するから注意しよう！_

## リスポーン
**死亡したチームメイトを復活させる**

アイテムを利用すると魔法陣を展開し、一定時間後にチームメイトを蘇生する。一定時間経過までに蘇生を試みたプレイヤーが死亡すると蘇生は失敗する。
蘇生されたチームメイトはチェーンフルアーマーと各種マップ、トライデント(忠誠I)、ミニチャージャーx4を持った状態でリスポーンする。

_蘇生時は大音量と共に落雷が発生して、場所が丸わかりになる。安全なところを選んで蘇生しよう！_

## ホスピタル
**範囲内のプレイヤーのシールドと体力を回復するヒールゾーンを展開する**
アイテムを使用すると15秒間半径5m以内のすべてのプレイヤーにHPの高速回復とシールドの回復効果を付与する

_全プレイヤー適応なので、インファイト時に敵も味方もいる状況で使うのは、両方が高速回復して戦闘が長引くだけだから、お勧めしないぞ！戦闘終了後の立て直しに利用しよう！_
